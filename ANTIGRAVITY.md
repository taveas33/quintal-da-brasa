# Orientação para continuar no Antigravity

Abra a raiz desta pasta, que contém package.json e vercel.json. Comece pelo README.md. Preserve o layout do template aplicado ao Quintal da Brasa e os refrigerantes existentes. Edite preços e produtos em data/catalog.json; npm run build atualiza public/product.js. Use npm run dev para visualizar e npm test para verificar. Nunca mova credenciais para public/. O .env está vazio e será preenchido pelo proprietário. As funções api/ são usadas no servidor local e na Vercel. Não publique nem gere cobranças reais sem a solicitação do proprietário.
